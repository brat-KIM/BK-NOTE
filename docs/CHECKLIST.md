# 실기기 확인 체크리스트

자동 테스트로 확인할 수 없는 것들. 단계가 끝날 때마다 여기에 쌓는다. 확인하면 `[x]`.

## P0 뼈대 (웹)
- [ ] PC 크롬에서 `pnpm dev` → http://localhost:5173 열어서 적기·엔터로 새 줄·Tab 메모·체크·지우기가 자연스러운지
- [ ] 한글 입력(IME) 중 엔터: 조합 중인 글자가 잘리거나 두 번 들어가지 않는지
- [ ] 형광펜 `Ctrl+Alt+H`, 취소선 `Ctrl+-`, 글자색 `Ctrl+Shift+C` 가 브라우저 단축키(확대/축소·개발자도구)와 충돌하는지 — 데스크톱 앱(P2)에서는 충돌 없음
