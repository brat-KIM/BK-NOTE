# 실기기 확인 체크리스트

자동 테스트로 확인할 수 없는 것들. 단계가 끝날 때마다 여기에 쌓는다. 확인하면 `[x]`.

## P0 뼈대 (웹)
- [ ] PC 크롬에서 `pnpm dev` → http://localhost:5173 열어서 적기·엔터로 새 줄·Tab 메모·체크·지우기가 자연스러운지
- [ ] 한글 입력(IME) 중 엔터: 조합 중인 글자가 잘리거나 두 번 들어가지 않는지
- [ ] 형광펜 `Ctrl+Alt+H`, 취소선 `Ctrl+-`, 글자색 `Ctrl+Shift+C` 가 브라우저 단축키(확대/축소·개발자도구)와 충돌하는지 — 데스크톱 앱(P2)에서는 충돌 없음

## P1 동기화 + PWA
자동 테스트로 확인한 것: 두 기기 전파, 오프라인 후 업로드, 본문 충돌 사본, 필드별 병합, RLS(다른 사용자 차단), 비로그인 거부, 새벽 정리 SQL — 메모리 서버와 실제 SQL(로컬 Postgres 16) 둘 다 같은 결과.

Supabase 프로젝트를 만든 뒤(docs/SETUP.md) 확인할 것:
- [ ] 이메일 로그인(링크 / 6자리 코드) 되는지
- [ ] PC 브라우저와 폰을 동시에 열고 적었을 때 **1초 안에** 반대쪽에 뜨는지 (제목줄 🟢 옆 ms 숫자 = 저장 왕복 시간)
- [ ] 폰 비행기 모드에서 적기 → 해제하면 PC 에 뜨는지
- [ ] 회사 네트워크에서 🟢(실시간) 유지되는지. 🔴 로 남으면 회사망이 WebSocket 을 막는 것 → 알려줘
- [ ] 다음 날 새벽 4시 이후 체크한 항목이 휴지통으로 갔는지 (pg_cron)
- [ ] 갤럭시 크롬 「홈 화면에 추가」 → 아이콘으로 실행 → 카톡에서 「공유 → BK-NOTE」

## P2 윈도우 스티커 앱
설치 파일: GitHub → Actions → **desktop-windows** → 최신 실행 → Artifacts 「BK-NOTE-windows」 (.exe 권장). 처음 실행 때 SmartScreen → 「추가 정보 → 실행」.
- [ ] 설치(관리자 권한 없이) → 실행 → 테두리 없는 세로 창이 뜨는지
- [ ] 제목줄 📌 로 항상 위 켜기/끄기, ⇥ 로 **가장 오른쪽 모니터 오른쪽 끝**에 세로로 꽉 차게 붙는지(작업표시줄 안 가림)
- [ ] 제목줄 잡고 끌어서 옮기기 → 껐다 켜도 그 자리(집·사무실 PC 각각 따로 기억)
- [ ] `Ctrl+Alt+Space` → 화면 가운데 빠른 입력 창 → 적고 엔터 → 사라지고 본 창에 들어오는지
- [ ] `Ctrl+Alt+N` 으로 숨기기/보이기, 트레이 아이콘 클릭·메뉴(보이기/빠른 입력/오른쪽 붙이기/종료)
- [ ] X 를 눌러도 꺼지지 않고 트레이로 숨는지
- [ ] 재부팅 후 자동 실행되는지(설정에서 끄고 켤 수 있음)
- [ ] 설정 → 알림 테스트 → 윈도우 알림이 뜨는지
- [ ] 다음 날 문서 폴더에 「BK-NOTE 백업」 폴더와 json·md 파일이 생기는지(밤 9시 이후 1회)
- [ ] 다른 프로그램이 `Ctrl+Alt+Space`/`Ctrl+Alt+N` 을 이미 쓰고 있으면 알려줘(바꿀 수 있게)
- 참고: 자동 업데이트는 아직 없음(서명 키 필요). 새 버전은 Actions 에서 다시 받아 설치하면 덮어써진다.
